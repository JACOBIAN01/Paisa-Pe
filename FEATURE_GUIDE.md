# Paisa-Pe Feature Guide

This document describes the stable demo features. It is not an answer key and does not list seeded bugs.

## Wallet basics
The Home screen shows the sample wallet balance and shortcuts. Students can explore send money, add money, request money and the activity list.

## Cards
The Cards screen displays three virtual cards. The freeze switch changes the selected card's local status. No card network is connected.

## Budgets
The Budgets screen shows sample monthly limits and spending for common categories. Progress bars are calculated from the displayed values.

## Savings
The Savings screen displays sample goals. Users can create a goal and add a local contribution. Goal progress is shown with a simple progress bar.

## Bills
The Bills screen lists sample electricity, mobile, broadband and water bills. Confirming a payment only changes the local bill status.

## Beneficiaries
The Beneficiaries screen displays saved demo contacts. Users can search by name or UPI ID and add another sample contact.

## Reports
The Reports screen displays sample monthly spending and category totals. The chart is a basic React Native layout, not a charting library.

## Recurring payments
The Recurring screen displays a fixed list of example subscriptions and their next payment dates.

## Help and support
The Support screen links to FAQs and a local ticket form. Submitting a ticket adds it to the local list.

## Student guidance
Stay within JavaScript, React fundamentals and standard React Native components. Read the screen, its imported components and the context/data it uses before asking AI to explain a behaviour. Verify every AI-suggested finding by reproducing it in the app.
